# DAW test list, release 0.3 (draft)

Draft by the project lead, 28 Oct 2026. Rows are added as workers finish items. Final version becomes a public PDF in `docs/releases/` (no role names, internal paths or logs). Host: DAW. Mark each row OK / FAIL / note.

## Hearing tests (cannot be measured by numbers)
- [ ] Genre presets (MINIMAL, GOA, DARK PSY, DANCE, TRANCE, TECHNO, EMPIRIKAL): character fits the genre; kick and bass sit together
- [ ] New Init 1-5 start clean (no clipping, no hum)
- [ ] Duck Demo: the bass clearly makes room for the kick
- [ ] FUNDAMENTAL DUCK in PSY ROLLING BASS and GLIDE BASSES: kick tail is clear, bass still has weight
- [ ] MID BASS, HI BASS, SYNTH presets: peak and tails are pleasant
- [ ] BRAKE curves (A and B): each curve sounds as labelled
- [ ] LOOP: no clicks at the loop point
- [ ] SOUNDSTAGE: toggling each source on/off changes width/bass mono/enhance as described in HELP
- [ ] Shimmer, Maximizer MODE, Low Multiplier
- [ ] START per engine: layers enter one after another; sync to beats/bars lands on the grid
- [ ] Per-engine envelope length and curve
- [ ] TOP DECAY (noise decay up to ~2000 ms)
- [ ] MIX tab, AP/START, HALFTIME, KEEP/COMPARE
